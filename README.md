# 🚀 UserHub – User Management Dashboard

A modern, responsive User Management Dashboard built using **HTML, CSS, and JavaScript**. UserHub allows users to create, view, and delete user profiles with data persistence using LocalStorage.

## ✨ Features

- ➕ Add new users with profile information
- 👤 Display users in beautiful profile cards
- 🗑️ Delete user profiles
- 💾 Store user data using LocalStorage
- 🔄 Data persists even after refreshing the page
- 📱 Fully responsive design
- 🎨 Modern dark-themed UI
- ✨ Smooth hover effects and animations

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations and responsive design
- JavaScript – DOM manipulation and functionality
- LocalStorage – Client-side data persistence

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ankur182006/userhub-user-management.git
```

### 2. Open the project folder

```bash
cd userhub-user-management
```

### 3. Run the project

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
